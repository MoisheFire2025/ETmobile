# ETmobile

Sitio educativo mobile-first para explorar eye tracking desde un teléfono. Está preparado como sitio estático para GitHub Pages.

## Uso

1. Abre `index.html`.
2. Entra en **Abrir modo móvil**.
3. Permite la cámara frontal.
4. Ejecuta la calibración de nueve puntos.
5. Inicia el seguimiento.

La cámara requiere un contexto seguro (`https://`), por eso se recomienda GitHub Pages. El procesamiento se realiza localmente en el navegador.

> Esta demo es educativa. No equivale a un sistema infrarrojo PCCR/Falcon y no tiene finalidad clínica ni diagnóstica.

## Publicar en GitHub Pages

En GitHub: **Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save**. La URL será `https://MoisheFire2025.github.io/ETmobile/`.
